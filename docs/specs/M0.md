# M0 — Scaffold

Goal: a reproducible, accessible PWA and Worker skeleton that runs locally and in CI, with the
foundations for the rest of Hearth and no product features ahead of schedule.

## Delivered

- pnpm workspace with `apps/web`, `apps/worker`, `packages/shared`, root scripts and lockfile.
- React 19 + Vite 8 + strict TypeScript + Tailwind CSS v4, shadcn/ui conventions, focus styles and
  mobile-first app shell.
- Hono Worker with `GET /api/v1/health`, Zod output validation, request IDs, security headers, shared
  error envelope, minimal Durable Object / queue / cron stubs, and a typed RPC client.
- D1 binding, Drizzle schema/client, and the first SQL migration (`users`).
- Cloudflare config for production and `[env.staging]`, including D1, R2, queues, Durable Objects,
  cron and observability. Resource UUIDs are intentionally placeholders.
- Greek and English locale files, browser-language detection, persisted language switch, `Intl` dates
  and numbers, Greek-capable Source Serif 4 / Inter fonts, and the locale parity CI check.
- WCAG-minded design tokens for light and dark themes, including AA-safe interactive contrast.
- PWA manifest, generated any/maskable/apple-touch icons, offline page, update prompt, service worker
  navigation fallback and API exclusion.
- Biome, Worker-pool Vitest tests, Playwright smoke/language/360 px tests, and GitHub Actions CI plus a
  staging deploy workflow.
- M0 additions: staging config, `pnpm sim` foundation, token-efficient specs, and this spec.

## Acceptance checks

```sh
pnpm check:i18n
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm exec playwright test
```

`pnpm dev` starts `wrangler dev` on `http://127.0.0.1:8787` and Vite on
`http://localhost:5173`. Open the Vite URL for HMR; `/api` is proxied to Wrangler.

## Cloudflare resource setup (not run in this environment)

```sh
wrangler d1 create hearth-db
wrangler d1 create hearth-db-staging
wrangler r2 bucket create hearth-photos
wrangler r2 bucket create hearth-photos-staging
wrangler queues create hearth-jobs
wrangler queues create hearth-jobs-staging
```

Copy the returned D1 UUIDs into `wrangler.jsonc` (top level and `env.staging`) and update the staging
`APP_ORIGIN`. Then:

```sh
pnpm db:migrate:local
pnpm db:migrate:staging
```

Add `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` as GitHub environment secrets for `staging`.
Set application secrets with `wrangler secret put <NAME> --env staging`; the key list is in
`.dev.vars.example`.
